# 🏠 Family Expense Management — Fabric

A personal project migrating a local SQL Server home expense pipeline to a cloud-based **Microsoft Fabric** solution (Data Ingestion, SQL, Orchestration, and Power BI). Built as both a practical utility and a hands-on learning lab.

## 📂 Repository Structure
- `docs/` — Architecture and design decisions.
- `notebooks/` — Fabric notebooks and legacy Python scripts.
- `pipelines/` — Fabric data pipelines.
- `powerbi/` — Reports and project files.
- `tests/` — SQL validation scripts.
- `warehouse/` — SQL schemas, views, and stored procedures.

## 🚀 Project Status
- ✅ **Phase 0 (Baseline): Completed.** Legacy local SQL Server and Python ETL codebase committed as the starting point.
- ⏳ **Phase 1 (Foundation): Up next.** Core migration to Microsoft Fabric (Warehouse, Notebooks, Pipelines, and Power BI).
